# 2AIM
## Діагностичні дані

Система містить:
- 5 математичних тем;
- 25 діагностичних завдань;
- 3 рівні складності;
- 7 навичок;
- 5 типових помилок;
- зв'язки між базовими та складнішими навичками;
- тестові сценарії для перевірки роботи діагностики.

## Фронтенд

Папка `frontend/` — інтерфейс на HTML + CSS + JavaScript без фреймворків (дизайн-система NMT Gap AI).

Екрани: головна → адаптивна діагностика → результат (карта знань, типові помилки, пошук кореневої причини) → план повторення → тренування з драбиною підказок і чатом з AI-репетитором → повторна перевірка «Було / Стало».

### Запуск

1. Запустіть бекенд з кореня репозиторію:
   ```
   pip install fastapi uvicorn groq python-dotenv
   uvicorn backend.app:app --reload
   ```
   (ключ `GROQ_API_KEY` — у файлі `.env`)
2. Відкрийте `frontend/index.html` у браузері або запустіть статичний сервер:
   ```
   cd frontend
   python -m http.server 5500
   ```
   і перейдіть на http://127.0.0.1:5500

Адреса бекенду — у `frontend/config.js` (за замовчуванням `http://127.0.0.1:8000`), або через параметр `?api=...` в адресі сторінки.

Якщо AI недоступний, план і підказки показуються в базовому вигляді без AI, тож демо не зупиняється. Правильні відповіді фронтенд ніколи не показує.

Назви тем, типових помилок і звʼязки навичок продубльовано в `frontend/script.js` (`TOPICS`, `MISCONCEPTIONS`, `SKILLS`), бо бекенд поки не віддає їх через API. Змінюючи `data/`, оновіть і їх.
